# Breath — Digital Garden Theme

Breath is a minimalist theme engineered for software engineers, systems thinkers, and technical writers who want to cultivate evergreen notes alongside traditional long-form engineering essays.

### Key Highlights
- **Stacked Notes:** Andy Matuschak-style cascading pane navigation.
- **Zero-FOUT Typography:** Local Yanone Kaffeesatz & JetBrains Mono fonts.
- **Media Previews:** Automatic rich embeds for YouTube, SlideShare, and presentations.
- **Content Separation:** Content directory is decoupled and safe from upstream git pulls.
